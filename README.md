# JaxLUG™ Kernel Config Project - KCP

This repository contains the official Jacksonville, Florida, Jacksonville
Linux Users Group™ community Kernel Config Project (KCP).

This is the JaxLUG's Kernel Config Project's "Penny Jar" repo, as in if you
need a config, take a config, if you have a config, submit a config.

This project is intended to aide in making custom kernels through sharing user
kernel configs. Anyone may submit their kernel config to the repository for
others to use as a starting point for theirs, or directly if on identical
hardware, or other helpful purpose.

## Categories

The repository is categorized in the following directories, more can be added
as needed.

- cloud
- desktop
- embedded
- laptop
- server

## Format

Within each directory, configs should follow the following format, subject
to change, which will be updated here accordingly. Not all fields are
required. If a custom system, go with the mother board model.

```c++
<vendor>-<model>-<gen>-<type>-<arch>-<version>-<distro>.config
```
